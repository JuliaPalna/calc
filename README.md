# Начало работы с умным калькулятором
Проект представляет собой веб-приложение, которое объединяет функционал калькулятора и конвертера единиц. Приложение реализовано с использованием React.js и включает в себя такие хуки, как useContext, useRef, useEffect, а также создание пользовательских хуков для управления состоянием и логикой приложения.

## Почему калькулятор?
Для первого приложения на React я решила выбрать создание калькулятора для освоения и прокачки навыков.
Проект демонстрирует применение современных технологий React для создания интерактивных пользовательских интерфейсов. Использованные хуки и контексты позволяют облегчить управление состоянием и улучшить пользовательский опыт

## Stack:
React / JS / Chakra UI / Axios/ Cheerio / VS Code

# Архитектура приложения
Проект структурирован с использованием компонентов и хуков, что обеспечивает легкость в управлении состоянием и переиспользовании логики.

## Компоненты приложения

### Калькулятор:
Основной компонент калькулятора. Содержит кнопки для цифр и операций, панель вывода информации.

### История операций калькулятора:
Компонент, отвечающий за отображение истории операций калькулятора. Использует хуки: createContext, useContext, useState.

### конвертер:
Компонент, отвечающий за конвертацию единиц. Включает выпадающие списки для выбора единиц измерения.
Использует useEffect для синхронизации поведения между выбором исходной и целевой единицы.

### Тема:
Обеспечивает доступ к теме приложения (светлая или темная) всем компонентам.
Использует useColorModeValue (из библиотеки Chakra UI) для управления состоянием темы.

### Пользовательские хуки:
useCalculator: Пользовательский хук для калькулятора, который управляет состоянием операций и вычислений.
useConverter: Пользовательский хук для преобразования значений между разными единицами измерения.
